# ค่าตั้งการวิเคราะห์

แก้ค่าที่ `recommendation_policy.json` แล้วรันโปรแกรมใหม่ ไม่ต้องแก้สูตรใน Python โปรแกรมหลักและสคริปต์เปรียบเทียบอ่านค่าชุดเดียวกัน ทุกค่าต้องมีครบและสะกดถูก โปรแกรมหยุดพร้อมข้อความหากค่าไม่ถูกต้อง

| ชื่อค่า | ค่าเริ่มต้น | ความหมาย |
|---|---:|---|
| train_fraction | 0.8 | Train 80%, Test คือส่วนที่เหลือ แบ่งตามปฏิทินก่อนกรอง missing |
| minimum_train_days | 150 | วัน Train ขั้นต่ำหลังกรองข้อมูล ห้ามต่ำกว่า 150 |
| minimum_test_days | 50 | วัน Test ขั้นต่ำหลังกรองข้อมูล อย่างน้อย 2 เพื่อคำนวณ SD |
| pca_target | 0.95 | สัดส่วนความแปรปรวนสะสมที่ PCA เก็บ ไม่ใช่ความแม่นยำ |
| shortlist_size | 10 | จำนวนหุ้นนอกพอร์ตสูงสุดที่จะทดลอง |
| candidate_weights | [0.05, 0.10, 0.15, 0.20] | น้ำหนักหุ้นใหม่แบบทศนิยม เช่น 0.20 คือ 20% |
| fee_rate | 0.001 | ค่าธรรมเนียมต่อมูลค่าซื้อ/ขาย เช่น 0.001 คือ 0.10% |
| fit_fraction_of_train | 0.75 | ใช้ Train 75% เป็น Fit ที่เหลือเป็น Validation |
| minimum_fit_days | 150 | วัน Fit ขั้นต่ำ ห้ามต่ำกว่า 150 |
| minimum_validation_days | 60 | วัน Validation ขั้นต่ำ อย่างน้อย 2 เพื่อคำนวณ SD |
| minimum_sd_reduction_percent | 5.0 | SD บน Validation ต้องลดอย่างน้อย 5% สัมพัทธ์ |
| maximum_return_loss_pp | 2.0 | ยอมให้ผลตอบแทนสุทธิลดไม่เกิน 2 จุดเปอร์เซ็นต์ |
| maximum_drawdown_worsening_pp | 0.0 | ยอมให้ Drawdown แย่ลงได้กี่จุดเปอร์เซ็นต์ |

ใช้ config ชุดเดียวกับทุกพอร์ตในการทดลองเดียวกัน ไม่ปรับให้ชนะ Test เดิมหลังเห็นผล ถ้าปรับวิธีจากข้อมูลที่เห็นแล้ว ให้ระบุว่าเป็นการสำรวจย้อนหลัง

ไฟล์ผลใหม่บันทึกค่าจริงที่ใช้ใน `reports/details/run_context.json` (`config`), `recommendation.json` (`policy`) และผลเปรียบเทียบหลายพอร์ตใน `reports/comparisons/contexts.json` รายงานเก่ายังคงเป็นหลักฐานการรันเดิมและจะไม่มีค่าตั้งใหม่จนกว่าจะรันใหม่

ค่าใน JSON ใช้ทศนิยมสำหรับสัดส่วนและ fee แต่เกณฑ์ SD/return/Drawdown ใช้หน่วยเปอร์เซ็นต์หรือจุดเปอร์เซ็นต์ตามตาราง อย่าใส่ 20 แทน 0.20 ใน candidate_weights
