# ข้อมูลราคา

วาง CSV ราคาเดิมของทีมที่ raw/sp500_daily_5years.csv คอลัมน์ขั้นต่ำ Date,Ticker,Close; วันที่ YYYY-MM-DD รองรับ OHLCV เพิ่มเติม

ยังไม่มีไฟล์ราคาต้นฉบับในโปรเจกต์นี้ reports เป็นผลที่เพื่อนแนบมา metadata เก็บพาธเครื่องเพื่อนตามจริง

python scripts/pulldata.py ดาวน์โหลด snapshot ใหม่มาที่ตำแหน่งนี้เมื่อจำเป็นเท่านั้น ข้อมูลใหม่อาจให้ผลต่างจากรายงานเก่า
