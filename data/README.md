# ข้อมูลราคา

ใช้ไฟล์ `raw/sp500_daily_5years.csv` ที่ผู้ใช้เตรียมไว้เอง คอลัมน์ขั้นต่ำ `Date,Ticker,Close` วันที่เป็น `YYYY-MM-DD` รองรับคอลัมน์ Open,High,Low,Volume เพิ่มเติม

เมื่อต้องการใช้ข้อมูลใหม่ ให้แทนที่ไฟล์นี้หรือกรอกพาธ CSV อื่นตอนรันโหมด 1 แล้วรันโปรแกรมใหม่ รายงานเดิมไม่อัปเดตเอง

CSV ต้องมีราคาหุ้นครบสำหรับพอร์ตที่เลือก และเหลือวันวิเคราะห์ตามจำนวนขั้นต่ำใน config ไม่เติมราคาที่ขาดให้อัตโนมัติ

เครื่องมือดาวน์โหลดเป็นตัวเลือกเพิ่มเติม: ติดตั้ง `py -m pip install -r requirements-download.txt` แล้วรัน `py scripts/pulldata.py` ผลอาจต่างจาก CSV ชุดเดิม
