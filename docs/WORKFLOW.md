# LongTripleTun — ขั้นตอนและสูตรที่ใช้จริง

คู่มือเทคนิคสำหรับสมาชิกทีม ส่วนวิธีเริ่มใช้งานแบบสั้นอยู่ใน [README](../README.md)

## ภาพรวม

โปรแกรมรับพอร์ตจาก CSV และอ่านราคาจาก CSV ที่ผู้ใช้เตรียม ใช้เวกเตอร์และเมทริกซ์สร้างทางเลือกเพิ่มหุ้น แล้วตรวจความคุ้มค่าก่อนให้คำแนะนำ หากไม่มีทางเลือกผ่านจะคงพอร์ตเดิม

```text
อ่าน config + CSV พอร์ต + CSV ราคา
                  ↓
ตรวจข้อมูล → ผลตอบแทน → แบ่ง Train/Test ตามเวลา
                  ↓
แบ่ง Train เป็น Fit/Validation ตาม config
                  ↓
Fit: Covariance → PCA → shortlist → ทดลองน้ำหนัก → เลือกระดับ
                  ↓
Validation: จำลองหลังค่าธรรมเนียม → ตรวจทุกเกณฑ์ → ล็อกทางเลือก
                  ↓
Test: ประเมินทางเลือกที่ผ่านโดยไม่เปลี่ยนการตัดสินใจ
                  ↓
เขียนทับรายงานและกราฟชุดเดิม
```

โปรแกรมยังวิเคราะห์ **Train ทั้งช่วง** เพื่อแสดงสูตรและตารางเปรียบเทียบประกอบ ทางเลือกจากส่วนนี้ไม่ใช่คำแนะนำสุดท้าย และอาจต่างจากทางเลือกที่สร้างบน Fit

## ค่าตั้งและข้อมูล

ทุกการทดลองอ่าน [recommendation_policy.json](../config/recommendation_policy.json) ตอนเริ่มรัน ใช้ค่าชุดเดียวกับโปรแกรมหลักและเครื่องมือเปรียบเทียบ ดูหน่วยและเงื่อนไขใน [คู่มือ config](../config/README_TH.md)

| ขั้นตอน | ค่าที่อ่านจาก config |
|---|---|
| แบ่ง Train/Test | `train_fraction`, `minimum_train_days`, `minimum_test_days` |
| แบ่ง Fit/Validation | `fit_fraction_of_train`, `minimum_fit_days`, `minimum_validation_days` |
| คัดหุ้น | `pca_target`, `shortlist_size` |
| ทดลองสัดส่วน | `candidate_weights` |
| คิดต้นทุน | `fee_rate` |
| ตรวจความคุ้มค่า | `minimum_sd_reduction_percent`, `maximum_return_loss_pp`, `maximum_drawdown_worsening_pp` |

ค่าต่าง ๆ ปรับได้ ไม่ใช่ค่าคงที่ในสูตร จำนวนวันขั้นต่ำของ Train และ Fit ลดต่ำกว่า 150 ไม่ได้

- CSV ราคา: `data/raw/sp500_daily_5years.csv` หรือพาธที่ผู้ใช้กรอก ต้องมี `Date,Ticker,Close` วันที่ `YYYY-MM-DD`
- CSV พอร์ต: `ticker,weight_percent` น้ำหนักเป็นบวก รวม 100% และชื่อหุ้นไม่ซ้ำ
- ตัวอย่างมาตรฐาน: `examples/portfolios/01_*.csv` ถึง `10_*.csv` เป็นพอร์ตสมมติสำหรับทดลอง ไม่ใช่รายชื่อแนะนำลงทุน
- เปลี่ยนข้อมูลราคาเองได้ แต่ต้องรันใหม่และระบุช่วงข้อมูลจริงในรายงาน
- โหมด 2 เป็นบทเรียนตัวเลขสมมติ ใช้ได้เฉพาะหุ้นใน `examples/learning/` ไม่ค้นหุ้นใหม่หรือสร้างรายงานตลาดจริง

## 1. ตรวจข้อมูลและสร้างผลตอบแทน

`price_data.py` อ่านราคา ตรวจชื่อหุ้น วันที่และราคาซ้ำ ราคาที่ไม่ใช่ตัวเลข ไม่เป็นค่าจำกัด หรือไม่เป็นบวกใช้คำนวณไม่ได้ ไม่มีการเติมช่องว่างหรือปรับค่าผิดปกติอัตโนมัติ

คำนวณเฉพาะคู่วันตลาดที่ติดกันใน CSV และมีราคาหุ้นในพอร์ตครบทั้งสองวัน ไม่ข้ามวันขาดแล้วเรียกว่าเป็นผลตอบแทนรายวัน:

```text
r[t,j] = Close[t,j] / Close[t-1,j] - 1
```

ราคา 100 → 102 ให้ผลตอบแทน 0.02 หรือ 2% หนึ่งแถวของเมทริกซ์ R คือหนึ่งวัน หนึ่งคอลัมน์คือหนึ่งหุ้น

เส้นแบ่ง Train/Test คำนวณจากปฏิทินข้อมูลก่อนกรอง missing เพื่อไม่ให้ข้อมูลขาดใน Test เลื่อนเส้นแบ่ง Train ส่วนการคัดหุ้นผู้สมัครใช้ราคาในช่วงฝึกที่กำหนดเท่านั้น หุ้นเดิมที่ไม่ผ่านจะทำให้หยุด ไม่ถูกลบออกจากพอร์ตเงียบ ๆ

## 2. เวกเตอร์และเมทริกซ์

น้ำหนักเปอร์เซ็นต์แปลงเป็นทศนิยมและเรียงให้ตรงคอลัมน์หุ้น:

```text
ผลตอบแทนพอร์ตแบบน้ำหนักคงที่: p = R @ w
ข้อมูลลบค่าเฉลี่ย:             X = R - mean(R, axis=0)
Sample covariance:            Σ = X.T @ X / (n-1)
Portfolio variance:           w.T @ Σ @ w
Portfolio SD:                 sqrt(w.T @ Σ @ w)
Correlation(i,j):             Σ[i,j] / (SD[i] × SD[j])
```

ตัวอย่างสมมติ `r = [0.01, -0.005, 0.02]`, `w = [0.5, 0.3, 0.2]` ให้ Dot product `0.005 - 0.0015 + 0.004 = 0.0075` หรือ 0.75% ตัวเลขนี้เป็นตัวอย่างสูตร ไม่ใช่ผลรันตลาดจริง

Norm วัดความยาวเวกเตอร์ Cosine วัดความคล้ายเชิงทิศทาง หากใช้เวกเตอร์ผลตอบแทนลบค่าเฉลี่ยจะได้ค่าเดียวกับ Pearson correlation เมื่อความแปรปรวนไม่เป็นศูนย์ ค่าที่ไม่มีนิยามต้องไม่ถือเป็นศูนย์

## 3. PCA และ shortlist

`candidate_analysis.py` สร้าง PCA ร่วมจากหุ้นเดิมและผู้สมัครบนข้อมูลช่วงฝึกเดียวกัน:

```text
ΣV = VΛ
L = V_k × sqrt(λ_k)
เวกเตอร์พอร์ตบนแกน PCA = w @ L
cosine(a,b) = dot(a,b) / (norm(a) × norm(b))
```

เรียง eigenvalue จากมากไปน้อย เลือกจำนวนแกนที่เก็บความแปรปรวนสะสมถึง `pca_target` แล้วเรียงหุ้นนอกพอร์ตตาม cosine กับพอร์ตจากน้อยไปมาก คัดสูงสุด `shortlist_size` ตัว โดยไม่ใช้ค่า cosine ที่ไม่มีนิยาม

Shortlist เป็นรายชื่อสำหรับทดลองต่อ ยังไม่ใช่คำแนะนำซื้อ ค่า cosine ต่ำไม่รับประกันว่าจะสวนทางพอร์ตในอนาคต PCA นี้ใช้ covariance ไม่ได้ปรับทุกหุ้นให้มีส่วนเบี่ยงเบนมาตรฐานเท่ากันก่อน

## 4. ทดลองน้ำหนักและเลือกระดับ

`rebalance.py` เพิ่มหุ้นผู้สมัครทีละตัวตาม `candidate_weights` ใช้เงินก้อนเดิม:

```text
น้ำหนักหุ้นเดิมใหม่ = น้ำหนักเดิม × (1-a)
น้ำหนักหุ้นใหม่     = a
```

คำนวณความเสี่ยงด้วย covariance เต็ม `w_new.T @ Σ @ w_new` ไม่ใช้ covariance ที่ประมาณจากแกน PCA เลือกทางเลือกที่ลด variance ช่วงฝึกได้จริง โดยมีพอร์ตเดิมเป็นทางเลือกเสมอ

`risk_levels.py` เลือกทางเลือกที่ดีที่สุดต่อสัดส่วน จัดได้สูงสุด 3 ระดับตาม SD ที่ประมาณก่อนทดสอบ: ต่ำ ใกล้กึ่งกลาง และสูง หากระดับซ้ำหรือไม่มีทางเลือกที่ดีขึ้นจะแสดงน้อยกว่าสาม ระดับนี้ไม่ใช่คะแนนความปลอดภัยที่รับประกัน

## 5. ตรวจ Validation ก่อนแนะนำ

`recommendation.py` แบ่ง Train เป็น Fit และ Validation อีกครั้ง สร้าง PCA/shortlist/น้ำหนักบน Fit แล้วจำลอง Buy and Hold บน Validation หลังคิด `fee_rate`

ทางเลือกต้องผ่านทุกเกณฑ์ใน config: ลด SD เพียงพอ ผลตอบแทนสุทธิไม่ลดเกินที่ยอมรับ และ Maximum Drawdown ไม่แย่ลงเกินที่ยอมรับ เกณฑ์เหล่านี้เป็นนโยบายทดลอง ไม่ใช่มาตรฐานทางการเงิน

ล็อกหุ้นและน้ำหนักที่ผ่านก่อน Test ไม่ fit ใหม่ด้วย Validation หลังตรวจผ่าน หากข้อมูลไม่พอหรือไม่มีทางเลือกผ่านจะคงพอร์ตเดิม

HHI = `sum(w²)` และจำนวนหุ้นเทียบเท่า `1/HHI` ใช้ประกอบคำอธิบายความกระจุกตัวของน้ำหนัก ส่วน correlation คู่หุ้นบอกความสัมพันธ์เชิงเส้น ไม่ได้ยืนยันเหตุและผล

## 6. ประเมิน Test และต้นทุน

`holdout.py` จำลอง Buy and Hold จากราคาตั้งต้น: จัดสรรครั้งแรกแล้วปล่อยน้ำหนักลอยตามราคา ต่างจาก `R @ w` แบบน้ำหนักคงที่ในบทเรียน

ต้นทุนเริ่มต้นประมาณด้วย `fee_rate × sum(abs(w_new - w_old))` คิดมูลค่าซื้อและขายรวม ไม่หารสอง หักครั้งแรก ไม่คิดซ้ำรายวัน ไม่มีค่าขายปิดพอร์ตตอนจบ ภาษี slippage หรืออัตราแลกเปลี่ยน

เปรียบเทียบผลตอบแทนสุทธิ SD รายวัน และ Maximum Drawdown กับพอร์ตเดิมและการแบ่งเท่ากันในหุ้นเดิม Test มีไว้รายงานหลังตัดสินใจ ไม่ย้อนเปลี่ยนผลผ่าน Validation หาก Test ไม่ครบให้แสดงว่าประเมินไม่ได้ ไม่เลือกหุ้นอื่นมาแทน

Drawdown = `NAV / running_max_NAV - 1` ค่าติดลบหมายถึงลดจากยอดก่อนหน้า ไม่ใช่โอกาสขาดทุน SD ต่ำไม่ได้รับประกันว่า Drawdown จะดีกว่า

รอบใหม่สำเร็จจะเขียนทับไฟล์ผลเดิมและล้างผลเก่าที่ไม่ใช้แล้ว หากบันทึกไม่สำเร็จจะคืนไฟล์รายงานเดิม ไม่ควรรันหลายรอบพร้อมกัน

ข้อมูลตลาดจริงเปลี่ยนได้ อ่านผลรันจากไฟล์แทนการถือว่าตัวเลขในคู่มือเป็นผลปัจจุบัน รายงานหลักและรายงานเปรียบเทียบอัปเดตแยกกัน ต้องตรวจข้อมูลต้นทางก่อนนำมาเทียบ

## 8. ข้อจำกัดและการตรวจสอบ

รายชื่อหุ้นปัจจุบันใช้ย้อนหลังอาจมี survivorship bias ข้อมูลขาดหรือบริษัทมีประวัติไม่ครบอาจถูกคัดออก วันที่ขาดพร้อมกันทั้งตลาดตรวจไม่ได้จาก CSV เพียงอย่างเดียว ราคาปรับแล้วเป็นดัชนีการเติบโต ไม่ใช่ราคาส่งคำสั่งซื้อขายจริง

ผลชุดนี้เป็นการสำรวจย้อนหลัง หากปรับวิธีหลังเห็น Test เดิมแล้วต้องประเมินช่วงใหม่ก่อนอ้างผลนอกตัวอย่าง ไม่ปรับ config เพียงเพื่อให้ทุกพอร์ตผ่าน ไม่มีส่วนใดซื้อขายจริงหรือแก้ CSV พอร์ตอัตโนมัติ

ตรวจโปรแกรมจากรากโปรเจกต์ด้วย `py -m unittest discover -s tests -v` ผลรันอัตโนมัติไม่ใช่หลักฐานการทดลองกับผู้ร่วมชั้น
