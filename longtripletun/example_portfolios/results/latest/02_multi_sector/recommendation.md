# สรุปการตัดสินใจปรับพอร์ต

**ไม่มีทางเลือกผ่านเกณฑ์ความคุ้มค่าบน Validation จึงคงพอร์ตเดิม**

## พอร์ตกระจุกตัวแค่ไหน

- ถือ 8 หุ้น; หุ้นใหญ่สุด JNJ 15.00%
- สามอันดับแรกคิดเป็น 45.00% ของพอร์ต
- HHI = ผลรวมกำลังสองน้ำหนัก = 0.1300; เทียบเท่าถือเท่ากันประมาณ 7.69 ตัวในแง่น้ำหนักเท่านั้น
- Correlation เฉลี่ยถ่วงด้วยน้ำหนักคู่หุ้น (ไม่รวมแนวทแยง) = 0.2804
- คู่ที่ correlation ไม่มีนิยาม 0 คู่ (ไม่นับเป็นศูนย์)
- ค่าความสัมพันธ์ใช้ Train ก่อน Test; HHI ไม่วัดความซ้ำซ้อนของธุรกิจ และ correlation ไม่ใช่เหตุและผล

- AMZN / MSFT: correlation 0.6754
- AAPL / MSFT: correlation 0.6362
- MSFT / NVDA: correlation 0.6352
- AAPL / AMZN: correlation 0.5698
- AMZN / NVDA: correlation 0.5664

## เกณฑ์ความคุ้มค่า

- SD บน Validation ลดอย่างน้อย 5.00% เทียบพอร์ตเดิม
- ผลตอบแทนสุทธิลดไม่เกิน 2.00 จุดเปอร์เซ็นต์
- Maximum Drawdown แย่ลงไม่เกิน 0.00 จุดเปอร์เซ็นต์
- ประเมินหลังค่าธรรมเนียมสมมติ 0.100% ต่อมูลค่าซื้อ/ขาย
- ค่าเหล่านี้เป็นนโยบายทดลองที่แก้ได้ใน recommendation_policy.json ไม่ใช่มาตรฐานรับรองความคุ้มค่าหรือผลอนาคต

Fit: 2021-10-15 ถึง 2024-10-10 (751 วัน)
Validation: 2024-10-11 ถึง 2025-10-13 (251 วัน)
Test: 2025-10-14 ถึง 2026-10-13

สร้าง PCA/shortlist/น้ำหนักใหม่จาก Fit เท่านั้น ตรวจเกณฑ์ด้วย Validation แล้วล็อกน้ำหนักโดยไม่ fit ใหม่ก่อนประเมิน Test
ตารางวิเคราะห์เดิมที่ใช้ Train ทั้งช่วงยังเก็บไว้เพื่อเรียนและเปรียบเทียบ แต่ไม่ใช่คำแนะนำสุดท้าย

## ทางเลือกที่แนะนำให้พิจารณา

คงพอร์ตเดิม — ไม่มีคำแนะนำซื้อขายเพิ่มจากด่านนี้ จึงไม่มีค่าปรับพอร์ตเพิ่มในแบบจำลอง
การคงพอร์ตเดิมไม่ได้ยืนยันว่าพอร์ตเดิมปลอดภัยที่สุด แต่ยังไม่มีหลักฐานพอให้เปลี่ยนตามเกณฑ์นี้

เกณฑ์นี้เพิ่มหลังเคยเห็น Test ชุดเดิมแล้ว ผลรอบนี้จึงเป็นการสำรวจย้อนหลัง ยังต้องประเมินช่วงใหม่ที่ไม่เคยใช้พัฒนาวิธี ก่อนอ้างประสิทธิภาพนอกตัวอย่าง
